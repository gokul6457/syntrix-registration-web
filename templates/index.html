THE CHALLENGE

Four rounds.
Four ways to level up.

Each round builds practical skills through a team-based challenge. Read the rules before the event and come ready to think.

01PROGRAMMING

Code Bingo

Compete by solving basic Python, C and Java questions, then match your answers on the Bingo grid. Complete a valid line using coding knowledge, logic and speed.

02SQL

Script Game

Face 20 SQL questions in a glass-bridge challenge. Choose a path with each answer: correct answers lead to safe jumps, while wrong answers break the glass. Successful jumps pull the virtual rope towards your team.

03PROMPT ENGINEERING

AI Forensics: The Missing File

Investigate a missing-file mystery by examining digital evidence, hidden clues, emails, reports and images. Use effective prompts and connect the evidence to uncover what happened.

04DEBUGGING

A Survival Game: Debug to Survive

Explore a virtual survival map and solve debugging questions to overcome challenges. Collect the letters revealed along the way and use them to qualify for the final round.
